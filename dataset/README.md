
# Dataset Information

The AI Smart Waste Segregation System uses a combined dataset of 15,110 images.

The dataset was collected from multiple publicly available sources, cleaned, deduplicated and organized into four categories:

1. PLASTIC
2. E_WASTE
3. ORGANIC
4. RECYCLABLE

## Dataset Processing

The project includes scripts for:

- Dataset collection and organization
- Duplicate detection
- Near-duplicate analysis
- Image quality checking
- Dataset splitting
- Final dataset validation
